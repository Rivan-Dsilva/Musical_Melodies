# Musical Melodies 🎵

Musical Melodies is an interactive web application that allows users to explore various musical instruments through sound. Simply hover over an instrument card to hear its unique audio and learn about its musical background.

## Features

* Interactive instrument cards with hover effects
* Real-time audio playback on hover
* Collection of Indian and Western musical instruments
* Responsive design for desktop, tablet, and mobile devices
* Modern UI built with HTML, CSS, JavaScript, and Bootstrap

## Instruments Included

* Violin
* Cello
* Sitar
* Veena
* Tabla
* Mridangam
* Tanpura
* Bansuri
* Harmonium
* Sarangi
* Piano
* Harp

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap 5

## How to Run

1. Download or clone the repository.
2. Ensure all audio files (.mp3) and image files are in the project folder.
3. Open `index.html`  in your browser.

## Project Objective

The goal of this project is to provide an engaging way for users to discover musical instruments by combining visual interaction with authentic instrument sounds.
